# 网络切换 1.0 验收记录

日期：2026-11-11（Asia/Shanghai）。

## 构建与系统依赖

使用本机 Dev-C++ 的 TDM64 GCC 4.9.2、C++11 构建，三个产品 EXE 均构建成功。运行库静态链接；PE 导入表仅包含 Windows 系统 DLL，不要求安装开发工具或脚本运行环境。安装 EXE 约 4.9 MiB。

- 正式 WMI / IP Helper 识别代码：读取到 1 张 Wi-Fi、2 张有线候选设备；6 个 IP 接口设置可读。未修改配置。
- 托盘 --smoke-ui：创建图标和消息循环后自动退出，退出码 0；不连接后台服务。
- 安装器 --verify：内嵌 PE 文件结构检查，退出码 0。
- 安装器 --verify-files：仅解包到工作目录，两份解包 EXE 的 SHA-256 与构建输出完全一致。没有注册或启动服务。
- PE 系统依赖检查通过。
- 托盘启动单次采样：工作集 10848 KiB，私有字节 1740 KiB。仅供参考，未包含服务、WMI 首次加载或实际切换；不代表整套软件稳定占用。

安装验收权限检查：当前 Windows 进程不是管理员令牌（检查工具退出码 77），未执行服务安装或系统变更。需要用户在运行安装器时确认 Windows 管理员授权。
