# 网络切换 1.0.1：高 DPI 修复

本次调整安装器、设置窗口和托盘图标的显示：

- 清单声明 Per-Monitor V2 DPI 感知，提供旧版 DPI 声明回退。
- 安装器和设置窗口按显示器 DPI 创建系统界面字体，所有标签、下拉框、复选框和按钮统一应用。
- 收到 WM_DPICHANGED 后采用系统建议窗口位置和尺寸，按原始逻辑坐标重新布局，避免跨屏或往返缩放产生累计误差。
- 窗口标题和托盘按 DPI 加载图标，补齐 20、24、28、40、48 等精确尺寸图层。
- 安装注册版本更新为 1.0.1。

验证结果：实际运行正式安装器和设置窗口的窗口过程，在不改变显示设置的前提下发送模拟 DPI 变更。100%、125%、150%、200% 及往返缩放的字体应用、控件边界、图标尺寸、GDI 资源稳定性检查全部通过；Windows 报告窗口使用 Per-Monitor V2。新版托盘启动退出及安装器解包一致性检查也通过。

这不是在各分辨率物理屏幕上的目测验收，也没有替代先前版本尚待执行的真实网卡/服务集成测试。

使用：运行“网络切换_Setup_1.0.1_高清版.exe”覆盖安装，安装器会请求退出旧版并恢复其保持的设置。若当前使用独占模式或保留了优先级修改，升级时可能发生网络路径变化。

实现参考：[微软高 DPI 开发说明](https://learn.microsoft.com/en-us/windows/win32/hidpi/high-dpi-desktop-application-development-on-windows)。
