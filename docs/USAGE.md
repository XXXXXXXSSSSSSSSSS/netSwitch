# 网络切换 1.0.1（可安装测试版）

适用 Windows 10 / 11，64 位。双击同目录的“网络切换_Setup.exe”安装，确认 Windows 管理员授权。程序文件和后台服务使用 C++ 原生代码；运行不依赖 PowerShell、Python、.NET 或 Dev-C++。

## 首次使用

1. 先退出旧版脚本托盘程序。新版安装器会移除旧版的 NetSwitchTray 开机自启项目，但不会批量启用旧版禁用的网卡。
2. 安装结束后，点击任务栏右下角的网络切换图标；图标可能在隐藏图标区域。
3. 点击“设置”，明确选择一张 Wi-Fi 和一张有线网卡，然后保存。未选择网卡时不会执行切换。
4. 默认使用“优先模式”，点击“优先 Wi-Fi”或“优先有线”。目标必须已连接，两张网卡必须启用。
5. 如果网卡被旧版禁用，可在选择网卡之后点击“重新启用选定 Wi-Fi / 有线网卡”。这是一项明确的修复操作，启用状态会保留。

## 两种模式

优先模式：将选定网卡的 IPv4 / IPv6 接口优先级调高，将另一张调低，保留网卡启用。IPv4 / IPv6 配置不一致时拒绝操作，不擅自启用或禁用协议。VPN、特定目的地址的路由和已有连接可能仍走其他路径。这不是网络隔离功能，也不保证互联网可达。

独占模式：在设置中主动勾选并确认后可用。先启用并等待目标网卡连接和 IP 地址就绪，再停用另一张选定网卡。可能中断远程连接、下载和内网访问。目标未就绪时保留另一张网卡并尝试恢复。此模式不会修改第三张网卡。

## 恢复与退出

每次系统修改前写入后台服务管理的恢复文件。菜单“恢复原设置”和“退出并恢复原设置”会撤销仍匹配程序写入值的修改；遇到其他程序修改、设备被拔掉或记录损坏时保留恢复文件并报错。恢复不是无条件的网络重置。

托盘进程意外结束后，后台服务会尝试恢复；系统突然断电或服务崩溃后，服务再次启动时会尝试恢复。恢复失败不会删除记录，后续可接回设备重试。硬件故障、策略阻止或并发修改等情形不能保证自动恢复。

开机启动只启动托盘，不自动切换或重新应用上次选择。开机自启可在安装时取消，也可以从托盘菜单调整。网络参数影响整台电脑；同一时间只允许一个托盘进程控制修改。

## 卸载

在 Windows“设置 → 应用 → 已安装的应用”中找到“网络切换”，选择卸载。卸载器先请求退出托盘和恢复原设置，再停止服务。存在未恢复记录时会中止卸载并保留软件与记录，请先接回原网卡并恢复。临时卸载器可能保留到下次重启清理。

## 数据和安装位置

- 程序：Program Files 下的 NetSwitchNative 文件夹。
- 恢复文件：ProgramData 下的 NetSwitchNative 文件夹，仅系统和管理员可写。
- 用户配置：当前用户的 Software\\NetSwitchNative 注册表项。
- 服务：NetSwitchNative，以系统权限运行；只接受安装时指定用户的本地受限操作。
- 不收集 Wi-Fi 密码，不配置 IP 地址、DNS 或网关，不内置外部服务器联网探测。

## 当前验收边界

23 个正式代码的模拟切换/恢复场景已在 Windows 运行通过，恢复日志使用真实文件读写；网卡读取、托盘启动退出、安装器解包一致性也已验证。尚未在隔离 Windows 环境中验证真实网卡禁用/恢复、管理员安装与卸载、服务崩溃/断电、休眠和多用户场景。因此本版本作为测试版交付，不能视为已完成全部实机验收的稳定版。详细内容见“网络切换_验收报告.md”。
